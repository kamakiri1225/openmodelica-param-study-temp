# パラメータスタディ（pairplot）手順

統一タンクモデル（`001_cup_tank`）の集中定数式を使い、設計因子を **LHS（ラテン超方格
サンプリング）** で振って **pairplot** を描く。OpenModelica は不要（Python の集中定数式のみ）。

## 1. 実行手順

```bash
cd 001_cup_tank/paramstudy
python pairplot_tank.py --n 300     # 既定 300 設計点
#  画面表示なしなら:  MPLBACKEND=Agg python pairplot_tank.py --n 300
```

必要 Python パッケージ：`numpy matplotlib`。

**出力**
- `pairplot_off.png` … 温度管理**なし**
- `pairplot_on.png` … 温度管理**あり**（ダイキン3.5kW上限）

## 2. 何を振る／何を見る

**設計因子（LHS で振る 5 つ）**

| 因子 | 記号 | 範囲 |
|---|---|---|
| 発熱量 | `Q` | 400 – 5000 W |
| 上面熱伝達率 | `h_top` | 6 – 100 W/m²K |
| 水位 | `level` | 0.05 – 0.22 m |
| Lx倍率（幅） | `sx` | 0.8 – 2.0 |
| Ly倍率（奥行） | `sy` | 0.8 – 2.0 |

> Lx と Ly は**個別**に倍率（縦横を別々に）。固定は `h_side=9`, `h_bottom≒1.7`(空気層),
> `h_water_wall=200`, 外気 24.5℃。

**応答（各点から計算して表示）**：表面積倍率(1=実機)、体積 [L]、5τ [h]、5τ時の温度上昇 ΔT [K]。

**列の並び（左→右）**：発熱量・熱伝達率・水位・Lx倍率・Ly倍率・表面積倍率・体積・5τ・温度上昇ΔT。

## 3. 計算式（各設計点で）

- 総コンダクタンス：`UA = h_top·A_top + 直列(水→壁, 壁→外気/地面)`
- 5τ：`5·C/UA`（`C = 水の熱容量`）
- 温度上昇 ΔT（5τ時, 上限100K）：
  - 管理**なし**：`ΔT = 0.993·Q/UA`
  - 管理**あり**（ダイキン3.5kW上限）：`Q≤3500` は `ΔT=0`（外気に保持）、`Q>3500` は `ΔT=0.993·(Q−3500)/UA`

詳しい式の意味は `docs/cup_vs_cup_tank.md`（§4 基本式）、制御ゲインの根拠は `docs/control_tuning.md`。

## 4. ケース数

| 条件 | ケース数 |
|---|---|
| 温度管理なし | N（既定 300） |
| 温度管理あり | N（既定 300） |
| **合計** | **2N（既定 600）** |

`--n` で設計点数 N を変更（例 `--n 500` で計 1000）。あり側は Q≤3500W で保持、Q>3500W で上昇。

## 5. 図の見方

- **下三角＝散布図**（点の色＝発熱量Q, レインボー）、**対角＝ヒストグラム**、**上三角＝相関係数**（赤=正/青=負）。
- 相関線（回帰直線）は**引いていない**：`h_top↔5τ`(1/h) や `Q↔ΔT`(3500Wで折れる) など**非線形**が多く、
  直線を引くと誤解を生むため（生の散布＋相関係数で判断）。

**主な読み取り（管理なし）**
- `h_top ↑ → 5τ ↓`（≈ −0.74, 最強）：放熱が増えUAが大きく整定が速い。
- `Q ↑ → ΔT ↑`（≈ 0.44）、`表面積倍率 ↑ → ΔT ↓`（≈ −0.28）：大きいタンクほど温度上昇が小さい。
- `Lx倍率 ↔ Ly倍率 ≈ 0`（個別に独立）、`水位 ↑ → 体積 ↑`（≈ 0.67）。

**管理あり（ダイキン3.5kW）**
- `Q ↔ ΔT` が**ホッケースティック型**：Q≤3500 は ΔT=0、Q>3500 で急上昇（冷却能力の頭打ち）。
