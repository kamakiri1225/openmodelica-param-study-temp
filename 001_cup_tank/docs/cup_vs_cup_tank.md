## 2. cup → tank の違い（なぜ設定が変わるか）

1. **蒸発の有無**：桶は水面開放で**蒸発が支配的**なので `h_top≈45`（Chilton–Colburn 概算と整合）。
   タンクは蒸発がほぼ効かず `h_top≈11.2`（普通の自然対流）。
   同じ `h_top=45` をタンクに使うと `UA` が過大になり、最終到達温度が実測37.7℃に届かない。
   **底面はタンクが地面から15mm浮いており空気層で断熱的**（`h_bot≒1.7`）なので、放熱は**上面が最大・底面が最小**
   （上面482／側壁59／底面68W）。
2. **スケール**：発熱40倍・上面積250倍・熱容量約1000倍。結果、時定数が **23分 → 6.2時間**と桁違いに遅い。
3. **壁の扱い**：桶は壁センサ（U4-2）があるので水↔壁の4℃差まで `h_l=58` で再現。
   タンクは壁データが無いので `h_l=200`（壁≒水）。
4. **側面 `h=9` は cup と共通**（自然対流の物理値）、底面は15mm空気層で断熱。
   タンクで合わせ込んだのは**上面 `h_top` と 水位 `level` の2つだけ**。

## 3. 合わせ込み：どのパラメータを「何に」合わせたか

固定：`Q=610W`・`Tamb=24.5℃`・側面 `h=9`・底面 `h_bot`(空気層15mm)・`h_l=200`。
可変は2つだけで、**実測 eva5 の別々の特徴**に対応させる：

| 合わせ込みノブ | 値 | **合わせる相手（実測の特徴）** | 効く物理量 |
|---|---|---|---|
| `h_top`（上面のみ） | **11.2** | eva5 の**最終到達温度 37.7℃**（頭打ちの高さ） | $UA \to T_\infty + Q/UA$ |
| `level_fill`（有効水位） | **0.0755 m** | eva5 の**立ち上がりの速さ**（昇温カーブの傾き＝時定数） | $C \to \tau = C/UA$ |

**要するに**：`h_top`＝どこまで上がるか（到達高さ）、`level_fill`＝そこへ着く速さ、を別々に合わせている。

## 4. 基本式（両モデル共通の集中定数モデル）

水を1つの塊（温度 $T$、熱容量 $C$）とみなしたエネルギー保存：

$$C \frac{dT}{dt} = Q - UA\,(T - T_\infty)$$

- $C = \rho\,c_p\,V_w$（$V_w = A_\mathrm{top} \times \mathrm{level}$）… 水の熱容量 [J/K]
- $Q$ … 投入熱 [W]
- $UA$ … 総熱コンダクタンス [W/K]（各面の $h\cdot A$ の和）
- $T_\infty$ … 外気温 [K]

解（初期条件 $T(0)=T_\infty$）：

$$T(t) = T_\infty + \frac{Q}{UA}\left(1 - e^{-t/\tau}\right),\qquad \tau = \frac{C}{UA}$$

### 最終到達温度（飽和温度）
発熱と放熱が釣り合う最終水温（グラフの水平部分）。

$$T_\mathrm{final} = T_\infty + \frac{Q}{UA}$$

$UA$（$\approx h\cdot A$）で到達する高さが決まる。

### 時定数 τ
$e^{-t/\tau}$ の時間スケール ＝「熱容量 ÷ 熱コンダクタンス」。

$$\tau = \frac{C}{UA}\quad [\mathrm{s}]$$

各時刻での到達度 $1-e^{-t/\tau}$：

| 経過時間 | 到達度 | 係数 |
|---|---|---|
| $t=\tau$ | 63.2 %（定義点） | $1-e^{-1}=0.632$ |
| $t=3\tau$ | 95.0 % | $1-e^{-3}=0.950$ |
| $t=5\tau$ | 99.3 %（ほぼ整定＝最終到達温度に到達） | $1-e^{-5}=0.993$ |

## 5. 温度管理（冷却）を付けられるか → 可能

このタンクにも温度管理を追加できる（`002/003_tank_para` の TempCtrl と同じ考え方）。

- 水温センサ → 目標温度（例：外気24.5℃）との差 → PID → **冷却熱流**（負のQ）を `tank.heatPort` に戻す。
- 冷却ゲインを 0 にすれば「温度管理なし」（本モデル＝37.7℃到達）、大きくすれば水温を目標に保持。
- 実冷却能力の上限（例：ダイキン3.5kW）を課すと、発熱>能力で保持できず上昇する挙動も再現可能。

→ 別ファイル `TankHotWater_cyclone_cup_TempCtrl.mo`（本モデル＋レギュレータ、ゲイン切替）として追加可能。
